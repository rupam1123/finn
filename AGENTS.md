# FINN project contract

Read `handoff.md`, `docs/final-pack-status.md`, `docs/master-execution-plan.md` and `docs/plan-review.md` before changing the project. Official main brief > companion reference > reviewed master plan. Dated checkpoints live under `docs/history`; their old test counts and setup commands are historical.

- Preserve Python FastAPI + SQLite and Next.js TypeScript/Tailwind. Deployment/runtime migration is not authorised by this source handoff.
- Keep deterministic financial arithmetic, explicit units/periods/currency/basis and primary-only Pull claims. Screener is staging/discovery.
- Do not invent values, live fixtures, causal price attribution, financial verdicts, model-stage success or acceptance results. Missing evidence remains a visible gap.
- Preserve source URLs and saved/publication/as-of times. HTTP read paths must not silently fetch upstream data or run models.
- Preserve the exact 18-company assessment universe, aliases, existing icons/fonts, compact design, accessible evidence controls and read-only mode.
- Never delete or replace private `.env`, SQLite/WAL data, Git metadata or unknown user edits during source cleanup. Use the outer pack manager's check before apply.
- Test changed financial/parser/storage/security behavior. Keep fixtures, lockfiles and third-party notices. Report verification scope and unresolved gates truthfully.
- Actual AI chat/build-history export is separate from the decision log. Do not fabricate transcripts.
- A final source package is not deployment approval or a financial/legal compliance certification. Provider/model acceptance, licensing choices and actual-device checks remain open as listed in the handoff.
