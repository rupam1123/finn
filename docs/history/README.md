# Historical records

This folder preserves dated implementation/verification checkpoints, earlier design/setup reports, the superseded 31 October handoff and the original export manifests. They establish provenance; they are not a statement that their old status or commands still describe the current app.

Use the current [handoff](../../handoff.md), [status](../final-pack-status.md) and [setup](../final-pack-setup.md) for continuing work. The latest UI refinement checkpoint is [Universe, dialogs and telemetry](checkpoints/universe-dialogs-telemetry-update.md).

Historical source manifests describe their original exports. Current payload hashes are in the **outer final pack's `package-manifest.json`**. The pack manager keeps an external receipt for changes and quarantine. Actual AI chat/build history must be exported separately.
