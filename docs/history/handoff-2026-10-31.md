## Reproduction
Use Python 3.12 per project recommendation and existing backend/requirements.lock.txt, then install editable backend. Current test run used Python 3.13.9 with versions in verification/day3-environment.json; exact original lock environment was not reproduced. Install pytest-cov for coverage. Frontend uses npm ci and existing package-lock.json.

From project root, set PYTHONPATH=backend and FINN_DB=data/finn.sqlite3. Start the backend with python -m uvicorn finn.main:app --host 127.0.0.1 --port 8000. Start exactly one separate worker with python -m finn.pull_jobs --db data/finn.sqlite3 --watch. Start frontend with npm run dev in frontend. POST /api/pull/{ticker}/jobs only queues work; a running worker is required.

Stop the worker before serialized CLI ingestion: python -m finn.pull --db data/finn.sqlite3 --symbols INFY DEEPAKNTR HDFCBANK KPIL. --warm covers portfolio/showcase; --saved-only reprocesses saved evidence; --force bypasses cache. --use-model requires a locally configured GEMINI_API_KEY. Never put secrets in NEXT_PUBLIC variables. Stop every other worker before --recover.

Validation: python -m pytest backend/tests -q --cov=finn; python scripts/verify_pull_sources.py --db data/finn.sqlite3; frontend npm run build and npm run typecheck; python scripts/run_integration.py --db data/finn.sqlite3 --out verification/local-integration. This environment required npm run build -- --webpack because Turbopack helper port binding was denied. The integration runner copies the DB, starts real HTTP servers and exercises React through jsdom; it is not mobile-browser QA.
