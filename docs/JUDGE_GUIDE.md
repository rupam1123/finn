# Judge walkthrough · FINN

Use the local app with the operator's saved database, or a deployment that the operator has subsequently verified. The private GitHub repository contains source and fixtures, not private runtime data. Deployment is currently paused.

## Five-minute review

1. **Welcome → Inbox:** note the short entry flow and solid light/dark appearance. Inspect the saved check dates before changing the filing window. Open a source-backed filing; compare surfaced and Routine items.
2. **Radar:** expand thresholds and inspect a timeline. Look for the separation of known-at-cutoff filings and later observations; no causal price attribution is asserted.
3. **Research → TCS:** read the compact brief, expand detailed analysis and open a source quotation/page/PDF.
4. **Ask FINN:** choose a topic. Excerpts are labelled as source text; explicit owner AI summaries, when enabled, are separate review-required drafts.
5. **Say–Do → Financials:** compare period coverage with actual matched-comparison count. Inspect units, scope and period in a reported statement. Check a lender such as HDFCBANK to see the separate schema.
6. **Outside the prescribed set:** inspect saved KPIL research where available. This demonstrates an unseen-company path, not universal ticker coverage.

## Why these choices matter

| Review question | FINN's implementation |
| --- | --- |
| Can I verify a claim? | Citations retain exact quotes, page numbers, source URLs, observed time and saved PDF identity. |
| Can AI invent arithmetic? | Financial calculation paths use deterministic Python/Decimal and explicit basis/period guards. |
| Does four-quarter coverage imply success? | No. Coverage and comparable numerical outcomes are counted separately. |
| Are all alerts causal explanations? | No. Temporal context and retrospective observations remain distinct. |
| Will reading spend model quota? | No. API reads use saved state; model generation requires explicit owner opt-in and POST. |
| What happens when evidence is missing? | The app retains a gap/review/not-comparable state rather than forcing a favourable demo result. |
